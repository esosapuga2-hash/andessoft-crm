# AndesSoft CRM

## Sistema de gestión de clientes y ventas

**Proyecto académico – Organización Empresarial – UTN**

### 1. Descripción del proyecto

AndesSoft CRM es una propuesta de sistema de gestión orientada a organizar y centralizar la información de clientes y oportunidades comerciales de una empresa ficticia de desarrollo de software.

El proyecto busca mejorar la administración de los datos, facilitar el seguimiento de oportunidades de venta y favorecer la comunicación entre las distintas áreas de la organización.

### 2. Objetivo general

Diseñar una propuesta de sistema CRM que permita gestionar información de clientes, registrar oportunidades comerciales y realizar el seguimiento de los procesos de venta.

### 3. Alcance del proyecto

El sistema contempla las siguientes funcionalidades:

- Registro y consulta de clientes.
- Almacenamiento de información comercial.
- Registro de oportunidades de venta.
- Seguimiento del estado de las oportunidades.
- Derivación de oportunidades a proyectos.
- Organización de las tareas mediante un tablero de gestión.

### 4. Historias de usuario

- **HU-01:** Registro y consulta de clientes.
- **HU-02:** Registro y seguimiento de oportunidades de venta.
- **HU-03:** Derivación de oportunidades a proyectos.

### 5. Herramientas utilizadas

- GitHub para el control de versiones y almacenamiento del repositorio.
- GitHub Projects para la planificación y gestión de tareas.
- GitHub Issues para documentar las historias de usuario.

### 6. Organización del trabajo

El proyecto se organiza mediante un tablero Kanban con tres estados:

- Por hacer.
- En progreso.
- Listo.

Se utiliza una rama secundaria para trabajar sobre la documentación y posteriormente integrar los cambios mediante un Pull Request con revisión.
